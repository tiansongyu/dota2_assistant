# 技术风险与验证边界

| 风险 | 当前证据 | 处理与验收 |
| --- | --- | --- |
| 没有 Windows / DOTA2 实机 | 当前仅 Linux 宿主 | 实现可移植核心与 Windows 代码，交叉检查不替代实机 |
| 没有标注的真实 BP 截图 | 仓库初始为空 | 建立 fixture manifest 和评估工具；不得报告虚构准确率 |
| 已锁定与悬停相似 | 参考实现主要靠稳定帧 | 独立锁定证据，未校准保持候选，允许人工确认 |
| OpenDota 配额变化 | 真响应与旧文档有差异 | 实际 header/429 为准，保存断点，指数退避，不绕限制 |
| 3—5 年历史不完整 | 平台只提供可访问记录 | 保存范围与导入数，空结果不能解释为没有比赛 |
| 头像授权 | 数据集代码许可不自动涵盖 Valve 美术 | 记录来源；用户本地模板导入，发行前审核素材分发权 |
| 当前版本/分段总体统计缺少可靠来源 | 不预设接口能力 | 接口预留；没有数据时明确缺失，不显示伪预测胜率 |
| 分辨率、UI 更新与超宽屏 | 线性缩放不足以保证槽位正确 | 分辨率/DPI/UI 版本独立 profile，失配拒绝识别 |
| SQLite 损坏 | 可能导致历史无法读取 | 启动检查和明确错误，保留原文件；不静默重建覆盖 |
| 全屏/最小化/多显示器 | WGC 实际表现取决于系统和游戏 | Windows 验收矩阵独立记录，退出/最小化停止无效工作 |
| 发布包与签名 | Linux 可测试不代表可发布 | Windows CI 构建与清洁机安装验收；签名凭证由发行者提供 |

当前工程参数（半衰期、权重、识别阈值）是初始值，不是经过优化的结论。所有真实数据测试与合成算法测试分别标记。
