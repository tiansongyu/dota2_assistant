# 数据隐私

DPDA 不提供云账号、不上传截图、不收集遥测。历史和设置保存在本机，公开历史查询只使用用户输入的 Account ID。输入 ID 不代表 Steam 登录，也不验证账号所有权。

## 网络访问

桌面历史同步访问 OpenDota 的公开 API，提供查询账号和分页参数。模板脚本访问 Valve 的公开 CDN 下载头像；这是用户主动执行的操作，缓存不会自动上传。Linux 调试工具只有显式运行探测时访问相应服务；可选凭证从环境变量读取，不写报告或数据库。第三方平台会按其服务政策处理网络请求。

当前对局不查询对手 Steam ID 或个人历史，不读取游戏内存、注入进程或截获游戏网络。WGC 只捕获选定 DOTA2 窗口，裁剪区域留在本机。可视化校准载入的图片也只在本地处理。

## 保存与删除

- Windows：通常位于 `%APPDATA%\io.dpda.desktop\`，以 Tauri 实际解析的应用数据目录为准。
- Linux 调试 GUI：通常为 `$XDG_DATA_HOME/io.dpda.desktop/`，未设置时使用 `~/.local/share/io.dpda.desktop/`。
- CLI：`--db` 指定的路径。API 诊断 JSON 保存位置由调用者的输出重定向决定。

主数据库文件为 `dpda.sqlite`，日志在 `logs`。关闭应用后，可备份整个目录；SQLite 运行中可能存在 WAL/SHM 文件，不要只复制主文件作为一致性备份。删除本地数据前先退出程序，再删除相应文件；恢复依赖自己的备份或重新同步公开数据。

截图、诊断和日志可能包含账号、窗口标题、文件路径或游戏界面信息。提交公开 issue 前应检查并移除不必要内容。仓库测试 fixture 使用公开研究账号，保留最小字段与采集说明；这些数据不作为用户默认账号。
