# Outdraft 功能参考

核验：2026-11-03。依据官网公开介绍与操作指南；没有运行其安装包，也没有独立验证其模型或识别效果。DPDA 不复制其程序代码、图片或品牌。

| 官网介绍的功能 | DPDA 对应实现或决定 |
| --- | --- |
| 按位置推荐、每次选人后更新 | 当前五位置由用户指定；阵容实际变化后更新 Top 3—5 |
| 个人英雄池与个人禁用偏好 | 自动/手动/混合英雄池，明确排除优先；已禁用英雄硬过滤 |
| 分解英雄强度、对抗和协同 | 展示个人历史、去重样本、平滑及数据缺口 |
| 胜率及各英雄的概率影响 | 当前只有推荐评分；须有时间验证及校准证据才能增加本局概率 |
| 敌方下一手、对线和前后期分析 | 作为未来研究项，当前没有可靠位置/时间段总体数据，不显示推测数值 |
| 物品、技能、天赋与局内节奏 | 不属于本次个人 BP 助手第一阶段范围 |

功能来源：[Outdraft 首页](https://outdraft.org/)。

官网 Windows 指南介绍悬停空槽查看候选、点击固定候选列表和 Steam ID 个性化；DPDA 借鉴“当前阵容＋候选＋展开依据”的操作顺序，减少选人时切换页面。[Windows 操作指南](https://outdraft.org/en/how-to-use/windows/)

其指南要求写入 GSI 配置，Linux 版通过 Wayland 屏幕分享工作。DPDA 不接入 GSI；当前 Linux 版本只供 API、数据库和统计调试，Windows 视觉捕获与真实游戏验收另行执行。[Linux 操作指南](https://outdraft.org/en/how-to-use/linux/)

第三方关于兼容性、胜率、封禁或效果的宣传不作为本项目的验收依据。本项目当前没有“不会被封禁”或“可以提高某个百分比胜率”的保证。
