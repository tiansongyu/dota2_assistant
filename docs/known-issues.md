# 已知问题与待验收项

本列表区分已实现代码与尚未获得的验证。没有真实证据的项目不得在发布页标成通过。

1. **真实识别数据缺失**：尚未提供标注的真实 DOTA2 BP 截图。没有可报告的识别 accuracy/precision/recall/FPR；合成测试只验证算法与管线行为。
2. **Windows 游戏集成未验收**：WGC 代码已交叉编译检查，实际窗口、最小化、DPI、4K、超宽屏、多显示器、独占全屏、悬浮窗和 FPS 影响仍待实机。
3. **校准不是开箱即用**：需为当前 UI 建立十槽位、选人界面和独立锁定标记的 profile。没有锁定证据的头像不自动确认，可靠禁用检测目前仅支持手动输入。
4. **头像缓存与授权**：公开肖像已可下载，但不保证等同于选人槽位裁剪；不随源码或安装包分发 Valve 美术。
5. **历史覆盖与版本缺省**：平台只提供可访问历史。实际玩家列表 `patch` 缺省，保留为空；没有自动补全全部比赛版本和五位置事实。
6. **非严格天梯口径**：推荐排除 Turbo 和特殊模式，但未获取可靠 lobby_type，不能保证仅天梯记录。个人统计页面保留全模式历史。
7. **外部总体模型未接入**：`PopulationEvidence` 仅为协议预留。没有经过核验的当前版本/位置/分段总体数据，也没有训练或校准本局概率模型。
8. **回测边界**：时间前缀与已结束比赛检查已实现；缺少真实历史 BP 时间线，当前只评估空阵容的实际英雄选择覆盖，不能证明策略提升胜率。
9. **真实大历史与桌面端到端性能待验证**：桌面快照当前读取全部个人记录、重新聚合并传给前端；已有 [10k/50k 合成模块测量](reports/synthetic-performance.md)，但真实多年数据、IPC/渲染和 UI 性能仍需验证及分页/缓存优化。推荐计算有耗时，尚无游戏 FPS 数据。
10. **有限页预算**：CLI 的 `--max-pages` 是每次网络请求预算。恢复会从首页去重重扫，始终使用很小预算会重复前几页；正式继续同步应省略预算。无稳定 provider 游标时不承诺跨段快进。
11. **第三方凭证**：OpenDota 基础公开请求已实测。STRATZ/Steam 可选探测没有凭证时明确未配置，不代表其历史同步已实现。
12. **开发安装包**：[v0.1.0-dev.1](https://github.com/tiansongyu/dota2_assistant/releases/tag/v0.1.0-dev.1) 已通过 Windows CI 安装后进程启动检查；尚未签名，未完成清洁用户机器安装验收。目标机器需预装 Microsoft VC++ x64 Runtime，安装包尚未自动处理该前置依赖。OpenCV DLL 还导入 `MFPlat.dll`、`MF.dll`、`MFReadWrite.dll`，Windows N 或精简系统的媒体组件依赖未验证。Linux CLI 是调试版本，不提供 Linux 游戏捕获或正式游戏悬浮体验。
13. **派生统计缓存**：当前英雄统计、对抗与协同由规范化比赛实时计算，尚未物化为专用持久化统计缓存；未来可按数据修订号缓存，避免维护相互不一致的重复统计。
14. **位置为规则推断**：`main` 已自动分析队内经济、补刀和分路，并显示样本和多位置候选；尚无已标注真实位置集的准确率或概率校准。终局资源可能受崩线/职责变化影响；四/五号位保持并列，详情采样有请求预算，不等于分析全部历史。CLI 回测暂未接入按时间重建的自动位置池。
15. **下载版与源码差异**：`v0.1.0-dev.1` 不含自动位置、逐场详情和 Linux 图形启动脚本；这些更新当前需从 `main` 构建。Schema 2 不能由旧版打开，使用隔离副本或提前备份。

复现、计划与验收见 [开发计划](development-plan.md)、[测试](testing.md)、[视觉系统](vision-system.md)。
